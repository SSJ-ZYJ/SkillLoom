# 来源、文字层与完整性

## 两个独立判断

| 观察                         | 能说明什么                          | 不能说明什么         |
| ---------------------------- | ----------------------------------- | -------------------- |
| 文字可选中、字符数多         | 有可抽取文字对象                    | 原生排版、文字准确   |
| 全页图像与隐藏文字重叠       | 很可能是扫描加 OCR                  | 必定来自某 OCR 软件  |
| 没有图片，文字为可见矢量对象 | 原生文字候选，也可能为 OCR 重排输出 | 没有经历扫描转换     |
| 中文乱序、错字、公式缺符号   | 抽取/识别内容不可直接采用           | 原页视觉内容同样错误 |
| 书签齐全、页数较多           | 便于定位，可能有更完整结构          | 未缺页、未重复页     |

保持 `来源类别` 与 `抽取可信度` 两列。`inspect` 输出的 image_area_ratio 是裁到页面范围的图片矩形并集覆盖率，hidden_text 是 invisible rendering mode（3）的文字线索；缩略图、蒙版、背景图、图像中文字和可见 OCR 均会影响判断。字体编码损坏也会使原生 PDF 抽取乱码。阈值只决定优先查看哪些页。

检查每章与所有异常类型页；原生候选也要把视觉原页与抽取结果并排核对。扫描衍生矢量版没有可靠的通用自动识别法：需要元数据、来源链、原始扫描及内容比对综合判定。无法追溯明确写“来源不明”，不用检测器制造置信度。

## OCR 工作路径

1. 原件只读，保存哈希；OCR 输出新副本，并保存工具、语言、参数和页码映射。
2. 先查看方向、分辨率、裁切和双页；必要时分离左右页，记录一对多映射，不能直接沿用原索引。
3. 本地 OCR 示例（需 OCRmyPDF、Tesseract、语言包及其系统依赖）：

```text
ocrmypdf --skip-text --deskew -l chi_sim+eng original.pdf searchable.pdf
```

`--skip-text` 只适合无文字页/混合文档补 OCR；对已有错误 OCR 层会跳过，不是修复命令。已有 OCR 层且保留扫描图时，可在确认工具支持后对副本试用 `--redo-ocr`；它与预处理选项有兼容限制，先查本机帮助。不对原生文字页盲用 `--force-ocr`，它会栅格化并可能丢失矢量信息。页码数量、图像和内容须在处理后重新核对。

4. 普通 OCR 不可信地还原数学布局。公式从清晰页面读出并重新排 TeX；低清公式裁片可单独提高渲染 DPI，但提高 DPI 不会恢复原图已经丢失的信息。
5. 视觉转写后复核：上下标、负号、指数、根号范围、分数线、希腊字母、角标、向量、集合、概率条件、单位、正负号、数值小数点、端口/IP/代码空白。
6. OCR 不明处保留位置与问题，不以学科常识假充原文；明确标注“补充推导/自编题”可以独立补充教学内容，但不能据此宣布缺失原题已恢复。

## 页码台账

结构清单每行记录：源 ID/哈希、PDF 页（1 起）、印刷页码、章节、页类型、缺页/重复/倒序状态、核验依据。连续区间可概括；异常处必须逐页记录。PDF 自带 page label 只是线索，不能替代视觉页眉/页脚。

- 跳号先检查是否漏扫、双页图、插图无页码、排版留白或附录；不直接认定缺页。
- 目录、正文开始、章节交界、习题末页、附录答案至少交叉验证。
- 缺页恢复必须核对版本、前后句衔接、公式/题号、页眉页码和图号。
- 完整性结论有范围：例如“所选章节已逐页核对”而不是无证据地说“全书完整”。

## 工具不能替代的事实

渲染哈希一致只证明复制结果一致；OCR 对置信度很高的负号错误仍可能给出错误结果；目录跳转成功不证明题解正确。三种证据分别记录，不能互相代替。
