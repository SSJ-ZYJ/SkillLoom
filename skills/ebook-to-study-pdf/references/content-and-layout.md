# 内容与版式验收契约

## 章节覆盖矩阵

为每章记录：学习目标、目录节覆盖、关键公式、机制/图、题型、原题/自编、缺页影响、来源页、数值复算结果、内容审核者与最终 PDF 页码。先保证必要内容，不复制所有重复推导。总结长度按学科难度和目标调整，不把旧项目页数当配额。

独立阅读检查应由未读原书的视角进行：

- 公式每个符号、单位、前提、适用范围明确；跨章必要背景已解释或内部链接。
- 题目含所有初始条件、边界条件、给定常数、图和待求量；“原书图 X”不能替代图。
- 解析说明模型选择和步骤；答案含单位、方向/符号、精度、合理性检查。
- 自编题显式标注，并独立重算；引用教材编号可以保留，但不是阅读前提。
- 网络题明确链路速率/长度、传播速度、分组数量、是否忽略排队处理、存储转发或流水线等假设。
- 物理题检查量纲、零/极限情形、能量或守恒关系、相位象限、参考系和近似条件。
- 实验概要说明输入、操作、预期现象、验证指标及权限限制，不凭空给出未执行结果。

## 语义内容框

沿用已有约定，Markdown 使用 Pandoc fenced div；LaTeX 使用同名加 `box` 的环境：

| class      | 用途                 |
| ---------- | -------------------- |
| objectives | 本章目标             |
| definition | 定义、概念           |
| mechanism  | 机制、协议、推导逻辑 |
| formula    | 公式与适用条件       |
| example    | 例题整体分组（可选） |
| problem    | 完整题目             |
| analysis   | 思路与解析           |
| answer     | 答案与验证           |
| pitfall    | 易错点               |
| takeaway   | 小结                 |

```markdown
::: {.problem title="题目：弹簧振子（自编）"}
质量为 $m=0.50\,\mathrm{kg}$ 的物体连接劲度系数
$k=200\,\mathrm{N/m}$ 的轻弹簧；忽略摩擦，求固有周期。
:::

::: {.analysis title="解析"}
由 $m\ddot{x}+kx=0$ 得 $\omega=\sqrt{k/m}$，所以
$T=2\pi\sqrt{m/k}$。
:::

::: {.answer title="答案"}
$T=0.314\,\mathrm{s}$（三位有效数字）。量纲为时间。
:::
```

不要把所有正文塞进框；有含义的框、表格线和示意图保留，章节之间靠标题与留白分隔。不使用独立 Markdown `---` 作分隔；filter 删除 HorizontalRule 而不处理 YAML 元数据分隔符。标题由显式章节 ID 隔离，避免重复 PDF 锚点；内部链接也须同步。

## 版式

- A4、单面、openany；正文 Noto Serif，标题 Noto Sans；中文使用对应 SC 系列，数学用支持数学的字体/宏包。
- 浅色蓝、绿、紫语义色，深色正文；不使用大面积深色底、低对比字或花哨封面。
- 正文先解决重复内容、宽表拆列/旋转或独立图，再局部调整；不以全书小字号解决溢出。
- 框可跨页；避免把 longtable 放进不兼容的框或浮动体。过长表格直接放正文，题干与答案不要无提示地隔离。
- 代码断行而不丢缩进；协议报文/时序图优先矢量重绘；图形带变量含义和清晰标题。
- 保留 `.tex`、图、filter、manifest；正文真源明确，生成文件的修改须回填真源。

## 最终验收证据

1. 原始/补充源的哈希、页码映射、缺页处置和每章覆盖矩阵。
2. 真实构建命令、退出结果、输出路径、最终 SHA-256、页数、页面尺寸及日志问题处置。
3. 全页联系表筛查记录与代表/疑似页大图检查记录；指出检查的页码。
4. 字体嵌入、文字/公式/图片、目录和书签的检查结果；“能打开 PDF”不是版式通过。
5. 干净重建后再验收最新 PDF；外部工具缺失和不可辨认内容明确标注，不能写成已验证。
