# 振动基础 {#oscillation}

这是一份自编排版样例，用于验证中文、公式、语义框与目录链接，不引用任何教材。

## 学习目标 {#goals}

::: {.objectives title="本章目标"}
说明理想弹簧振子的假设，计算角频率和周期，并用初始条件确定位移。
:::

::: {.definition title="模型与符号"}
质量 $m$ 的物体在水平无摩擦面上运动，连接劲度系数为 $k$ 的理想弹簧。
位移 $x$ 从平衡位置计量，时间为 $t$，回复力满足 $F=-kx$。
:::

::: {.mechanism title="从受力到运动"}
牛顿第二定律给出 $m\ddot{x}=-kx$。这是二阶线性方程，解可写成
$x(t)=A\cos(\omega t+\varphi)$，其中振幅 $A$ 和初相位 $\varphi$ 由初始条件决定。
:::

::: {.formula title="角频率与周期"}
在质量和劲度系数为正、回复力线性的前提下：

$$\omega=\sqrt{\frac{k}{m}},\qquad T=\frac{2\pi}{\omega}.$$

$\omega$ 的单位是弧度每秒，$T$ 的单位是秒。
:::

## 完整例题 {#worked-example}

::: {.example title="自编例题：由初始条件求位移"}
以下题目、解析和答案作为独立阅读与公式排版样例。
:::

::: {.problem title="题目"}
理想弹簧振子质量为 $0.50\,\mathrm{kg}$，劲度系数为 $200\,\mathrm{N/m}$。
水平面无摩擦，忽略空气阻力。在 $t=0$ 时，物体从 $x=0.10\,\mathrm{m}$ 处静止释放。
求角频率、周期以及位移随时间的表达式。
:::

::: {.analysis title="解析"}
角频率为 $\sqrt{200/0.50}=20\,\mathrm{rad/s}$。初始速度为零且位移为正最大值，
因此 $A=0.10\,\mathrm{m}$、$\varphi=0$。周期为 $2\pi/20$ 秒。
:::

::: {.answer title="答案与检验"}
$\omega=20\,\mathrm{rad/s}$，$T\approx0.314\,\mathrm{s}$，
$x(t)=0.10\cos(20t)\,\mathrm{m}$。代入 $t=0$ 得到原始位移；对位移求导得
$v(t)=-2.0\sin(20t)\,\mathrm{m/s}$，初始速度确为零。
:::

::: {.pitfall title="易错点"}
角频率 $\omega$ 与频率 $f$ 不同，二者满足 $\omega=2\pi f$。不能直接把角频率的倒数当作周期。
:::

先核对单位和模型假设，再代入数值。另一个带单位的例题见[第二章的单链路时延](#ch02-delay)。
:::
