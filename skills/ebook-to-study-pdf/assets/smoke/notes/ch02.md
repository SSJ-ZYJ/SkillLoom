# 链路时延 {#network}

## 单链路计算 {#delay}

::: {.objectives title="本章目标"}
区分发送时延与传播时延，完成字节到比特、千米到米的换算。
:::

::: {.definition title="两个时延"}
发送时延是把整个分组送上链路所需的时间；传播时延是信号经过链路所需的时间。
长度为 $L$ 比特、发送速率为 $R$ 比特每秒、距离为 $d$ 米、传播速度为 $v$ 米每秒时，
两者分别为 $L/R$ 和 $d/v$。
:::

::: {.problem title="自编题目"}
一个分组长 1000 字节，经一条 100 千米链路传输。发送速率为 $2\times10^6$ 比特每秒，
传播速度为 $2\times10^8$ 米每秒。不经过中间路由器，忽略处理和排队时延。
从发送第一个比特开始，到接收最后一个比特为止，需要多长时间？
:::

::: {.analysis title="逐步换算"}
分组长度为 $1000\times8=8000$ 比特，距离为 $100\times1000=100000$ 米。
发送时延为 $8000/(2\times10^6)=0.004$ 秒，传播时延为
$100000/(2\times10^8)=0.0005$ 秒，两者相加。
:::

::: {.answer title="答案"}
总时延为 $0.0045$ 秒，即 $4.5$ 毫秒。每个分式均为时间量，单位一致。
:::

以下代码独立复算题目数值：

```python
length_bits = 1000 * 8
rate_bps = 2_000_000
distance_m = 100_000
speed_mps = 200_000_000
delay_ms = (length_bits / rate_bps + distance_m / speed_mps) * 1000
assert abs(delay_ms - 4.5) < 1e-9
```
